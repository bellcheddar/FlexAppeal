{# The page used to say "double-click it on your Mac". It cannot work: a file downloaded over HTTP arrives without the executable bit, and Finder refuses it with "you do not have appropriate access privileges". The two commands below are what actually runs it, and the filename tracks the job name so they can be pasted as they are. #}

You will get one file. Run it from Terminal:

cd ~/Downloads
chmod +x flexappeal_run.command
./flexappeal_run.command

The chmod is not optional. A download has no executable bit, so double-clicking it in Finder will fail until you have run that line once. The first run installs the environment (several GB, 5 to 15 minutes); later runs go straight to simulating, and re-running resumes from the last checkpoint.
