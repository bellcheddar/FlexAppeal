What the state score means

For each motif, s compares how far it sits from the nearest active reference against how far from the nearest inactive one, as (dinactive − dactive) / (dinactive + dactive). It runs from +1, sitting on the active references, to −1 on the inactive ones. A normalised difference rather than a raw gap, so a three-residue motif and a twenty-residue loop land on the same axis instead of the larger one dominating.

Both distances are measured after superposing on the structural core, so what is reported is the motif moving rather than the whole protein drifting. conflict means the geometry and the published rule-based criterion disagree, which is shown rather than resolved.

Why these sit beside the state score rather than inside it

These are the published criteria for the protein family: the αC salt bridge and the regulatory spine for a kinase, the TM3–TM6 cleft and the ionic lock for a receptor. They are measurements, and the state score is an interpretation, so they are kept apart. Where one contradicts the score the motif is labelled conflict rather than averaged.

Helix rotations and the connector RMSD are measured against the start model after superposing on the structural core, so what is reported is the helix moving rather than the whole protein drifting. A structure compared with itself reads exactly zero, which is asserted in the tests.

Motif timelines

How to read these

One panel per motif. The two lines are this run's Cα RMSD to the nearest active and nearest inactive reference for that motif, after the core superposition, which are the two numbers the state score is built from.

The shaded bands are the 5th to 95th percentile of how far each reference of that state sits from the nearest other reference of the same state. So the band is the spread the ensemble already has, and a line inside it means this frame is as close to that set as the set's own members are to each other. A line far above both bands, which is what the activation loop does here, means the frame resembles neither set and the score between them should be read with that in mind.

A state with fewer than three references gets no band rather than one drawn through two points, so a missing band is a small ensemble and not a narrow one.

State score over time

How to read this

One line per motif, with the whole-protein score drawn in black on top: it is the residue-weighted mean of the motif scores, so a twenty-residue loop counts for more than a single tryptophan. Above {{ "%+.1f"|format(decisive_s) }} the geometry is calling a motif active-like and below {{ "%+.1f"|format(-decisive_s) }} inactive-like; between them it is intermediate, and the bands are drawn to show that.

The thick flat segment over each half of a line is that half's mean, and it is there because a noisy line is hard to read for direction. A motif that sits on a threshold crosses it repeatedly and looks like it is moving across it; two means level with each other say it is not. They are the same two numbers the table above prints, split at the same frame, so the picture and the table cannot tell you different things.

Where the run is long enough, the black line is a centred {{ "%.0f"|format(2) }} ns mean and the raw per-frame values are the faint line behind it. The smoothing is for reading the plot only: what is stored and what every number in the tables comes from is the raw series. On a run shorter than twice the window the smoothing is skipped rather than drawn, because a window wider than the data collapses every point to one value and that draws as a flat trace.

Why most of these say neither

Secondary structure is far less discriminating than geometry. Most residues of a transmembrane helix are helical in both states, so every agreement here is high and the differences are small. A lean is only called above a 0.05 margin, which was chosen from the observed spread: the motifs that discriminate separate by 0.07 to 0.15 and the ones carrying no signal by 0.02 to 0.04.

Where this does agree with the state score it is worth more than either alone, because the two share none of their machinery. For the kinase the hinge discriminates by neither measure: 0.18 Å from active against 0.16 from inactive, and secondary-structure agreements identical to three decimal places.

How to read the ribbon

One column per saved frame, one row per residue, coloured by the DSSP class. A motif unwinding shows up as a horizontal band changing colour part-way across. Computed with the full eight-class DSSP rather than the simplified three, because the difference between an α helix and a 3-10 helix is the kind of local change worth seeing.

A residue DSSP could not assign is left blank rather than drawn as coil: no assignment and an assignment of coil are different claims, and only one of them is evidence of anything.

How these are measured

Both readings are taken after superposing the frame on the same core the state scores use. That is the point of them: a ligand that holds its pose has not moved relative to the pocket, and one that drifts while the protein drifts with it has not come loose. Measured in the trajectory's own frame, the protein's tumbling would be reported as the ligand moving.

The pose RMSD is to this run's own first frame, not to a deposited pose: the question is whether the ligand stayed where this simulation started it. {% if ligand.symmetry_corrected %} It is minimised over the ligand's own symmetry, so a ring that flips end for end reads as the same molecule in the same place rather than as drift. {% else %} It matches atoms by index, because the ligand's graph could not be inferred, so a symmetric group that flips will overstate the drift. {% endif %}

What these should be

POPC at 303 K is expected to give {{ "%.1f"|format(apl_expected[0]) }} to {{ "%.1f"|format(apl_expected[1]) }} Å² per lipid and a phosphate-to-phosphate thickness of {{ "%.1f"|format(thickness_expected[0]) }} to {{ "%.1f"|format(thickness_expected[1]) }} Å. Area per lipid is the box cross-section divided by the lipids in one leaflet, with the leaflets split at their own midplane rather than at z = 0, because the bilayer drifts in z under a membrane barostat.

The badges mark each chunk against those windows. expected is inside them. outside expected is a chunk that is still usable: area per lipid has a wider acceptable range of {{ "%.1f"|format(apl_acceptable[0]) }} to {{ "%.1f"|format(apl_acceptable[1]) }} Å², and the first chunk after equilibration is often the one that sits outside the narrow window. G6 is outside even that, and raises the science gate on the run.

Tilt is the receptor's angle to the bilayer normal, taken as the mean direction of the seven transmembrane helix axes rather than the principal axis of the whole bundle. Inside a 37 Å bilayer the bundle is about as wide as it is tall, so it has no principal direction to measure and fitting one returns noise.

Why the core matters

Every motif distance here is measured after superposing on this core, so the core is the frame of reference the whole score is expressed in. It is chosen to be the part of the fold that does not move on activation; if it did move, the motif distances would report the core's motion instead.
