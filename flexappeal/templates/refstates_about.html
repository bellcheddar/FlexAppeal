How this works

A simulation tells you what moved. It does not tell you whether what moved went anywhere meaningful. These pages answer the second question by comparing every frame against the experimental structures of the same protein, so a motif's drift is reported as a distance from the active and inactive states rather than as a number with no scale.

Nothing here is hand-annotated. Kinase residues are resolved through the KLIFS pocket alignment and receptor residues through GPCRdb generic numbering, which means the same code names the motifs of a protein it has never seen, and a construct that renumbers is refused rather than measured at the wrong residues.

The two readings

Each motif is read twice. Geometrically, as how close it sits to the nearest active and nearest inactive reference after superposing on the part of the fold that does not move on activation. And by rule, using the published criterion for that motif, such as the DFG two-distance test or the ionic lock distance.

When they agree the motif is labelled active or inactive. When they disagree it is labelled conflict, and that is shown rather than resolved: a frame whose geometry has drifted one way while its rule-based criterion still reads the other is the interesting case, not noise to be averaged out.

Where the published thresholds did not hold

Two of them were recalibrated, and both for the same reason: the published number was fitted on crystal structures and sits at the edge of a cluster, which leaves no room for a side chain at 300 K.

  • The DFG two-distance criterion's {{ "%.1f"|format(dfg_published_a) }} Å cut called six of ABL1's own DFG-out references neither state. The two classes separate by 8.5 Å on the difference between the distances, so the state is read from which anchor the ring is nearer, and agreement with KLIFS goes from 11 of 17 to 17 of 17.
  • The regulatory spine's {{ "%.1f"|format(r_spine_published_a) }} Å contact distance clears the top of the active range by 0.04 Å. Moved to {{ "%.1f"|format(r_spine_a) }} Å, in the 4.4 Å empty region between the clusters, the references still classify perfectly and the trajectory stops reporting a permanent conflict. One reference turns on the choice: 2G1T, the Src-like inactive structure, has its deciding pair at 6.14 Å, so the published threshold calls its spine broken when it is intact.

What these runs are not

Each limitation below changes how a number on these pages should be read, so it is here rather than only in the build notes.

  • The ABL1 runs are dephosphorylated. The start structure carries phosphotyrosine at residue 393, the activation-loop tyrosine, and the force field ships no parameters for it, so it is built as plain tyrosine. Phosphorylation at that position is one of the main things that holds ABL1 active, so a drift towards the inactive state in the apo run has a physical explanation that has to be offered before any other.
  • One run per starting state, not three. Replicas were dropped for compute, so nothing here separates a conformational change from a single trajectory's excursion. A motif that moves once has moved once.
  • 50 ns is short for the question. The β2AR active-to-inactive relaxation these runs start from was observed on the microsecond scale, so its absence here is expected and is not evidence that the receptor is stable.
  • The scores are relative to a reference set. A frame is placed between crystal structures of the two states, so a frame that resembles neither is reported as intermediate rather than as something new.
  • The bilayer is pure POPC, and helix 8 is not anchored. A real plasma membrane has cholesterol, mixed chain lengths and charged headgroups, and cholesterol is known to occupy grooves on β2AR and change how it moves. The receptor is also palmitoylated at Cys341 in life, which tethers helix 8 to the inner leaflet; that is not modelled here. Helix 8's score and its angle to the membrane plane are therefore measured on a receptor that is freer at that end than the real one.
  • The apo runs start from structures that had something bound. b2ar_apo starts from 4LDE, solved with an agonist and a nanobody, and abl1_apo from 2GQG. Neither ligand is present, so the first part of each run is the protein relaxing out of a bound pose. On the receptor this is visible within the first nanoseconds: the TM3–TM6 cleft leaves the active reference cluster and spends the run between 10.3 and 15.3 Å, 97 per cent of its frames between 11 and 15, measured over the finished 50 ns rather than estimated from a partial one. That is the apo system behaving correctly, but it means the early frames of an apo row are not a sample of the state its start structure was labelled with.
  • The kinase set is small. KLIFS lists 12 active and 45 inactive ABL1 entries, but those are rows for individual chains: they collapse onto {{ counts.get("abl1", {}).get("active", 0) }} active and {{ counts.get("abl1", {}).get("inactive", 0) }} inactive depositions, and an active score is the distance to the nearest of those {{ counts.get("abl1", {}).get("active", 0) }} crystal structures. Eighteen of the inactive rows have an incompletely resolved activation loop.{% if counts.get("b2ar") %} The receptor is better served, with {{ counts["b2ar"].get("active", 0) }} active and {{ counts["b2ar"].get("inactive", 0) }} inactive structures.{% endif %}

Annotate your own trajectory

Nothing on these pages is specific to ABL1 or to the β2-adrenergic receptor. The same module annotates any kinase KLIFS knows or any class A receptor in GPCRdb, resolving that protein's own motif residues at run time, so a trajectory of a protein this build has never seen is scored by the same code against the same kind of reference set.

It is a command line entry point rather than a form on this page. A trajectory is too large to post through a browser, and the annotation downloads and superposes every reference structure for the target, which takes minutes rather than the seconds a request can hold open. 

python FlexAppeal.py refstates annotate \
    --topology system.pdb --trajectory run.dcd \
    --start start.pdb --family auto --out annotated.json

--family auto reads the structure's own sequence and returns unknown rather than guessing, because annotating a kinase as a receptor would resolve every motif to the wrong residues and still produce numbers. --start restores the deposited residue numbering, which OpenMM discards when it solvates. --protein names the target to the catalogue, as a KLIFS kinase name such as CDK2 or a GPCRdb entry name such as adrb2_human.

The honest limitation, measured rather than assumed: on an unseen target the reference ensembles are capped and the superposition core is taken from one reference, so a CDK2 score is a distance to fewer structures than an ABL1 one. The analysis reports how many references survived, and a run that kept too few says so in its own output instead of returning a confident number.
