A complete run, start to finish

This is T4 lysozyme L99A with benzene bound in its buried non-polar cavity — PDB 181L, X-ray at 1.80 Å — simulated for 100 nanoseconds in explicit water on an Apple M2 Ultra. It is the same three steps the two tabs either side of this one describe: configure a run, run the single file it hands you, upload what comes back.

The ligand is the point. A run with nothing bound draws the whole-system panels and not one of the eleven binding-site panels, so this cavity — the one the literature uses to ask what a buried non-polar site will hold — is what makes the rest of this page real.

1

Prepared

181L loaded from the RCSB, benzene kept and its bond orders taken from the chemical dictionary, hydrogens added at pH 7.4, solvated in a dodecahedral box with 1.2 nm padding and neutralised to 0.15 M NaCl. 3,023 solute atoms became 25,463 with 7,600 waters.

2

Ran

One .command file, run from Terminal. It parameterised benzene with OpenFF 2.2.1 and AM1-BCC charges, benchmarked the machine's platforms, minimised, heated to 310 K, equilibrated for 1 ns while releasing restraints, then produced 100 ns at 4 fs with hydrogen-mass repartitioning — 8.05 hours at 298 ns/day on OpenCL.

3

Analysed

The run packed a .fxa results file: metrics, a decimated trajectory and the topology to view it against. That file is committed to the repository, and it is what this page is rendering.

Reproduce it: the bundle is in the repository at {{ example.bundle }}. Download it, chmod +x it, and run it. The first run installs the environment; after that it goes straight to simulating.
