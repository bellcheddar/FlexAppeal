# FlexAppeal web app -- the droplet's dependency set.
#
# Deliberately pip-installable with no compiled toolchain: every package here
# publishes manylinux wheels, so `pip install -r requirements.txt` on a fresh
# Ubuntu box needs no build-essential and no conda. The heavy scientific stack
# (OpenMM, PDBFixer, OpenFF, AmberTools) is NOT here on purpose -- it belongs in
# the bundle that runs on the user's own machine, and nothing the web app does
# needs it.

flask>=3.0
gunicorn>=21.2
jinja2>=3.1
python-dotenv>=1.0

# Structure introspection for the Prepare tab: chains, heteroatoms, gaps,
# disulfides. gemmi parses both PDB and mmCIF, is fast, and is a single wheel --
# the reason it is here rather than Biopython, which would pull more for less.
gemmi>=0.6.5

numpy>=1.26

# Bounded server-side re-analysis of an already-decimated trajectory (the
# /reanalyse route). The atom-by-frame budget in analysis.py, and the MemoryMax
# on the systemd unit, are what keep this from being able to exhaust the box.
#
# MDAnalysis is deliberately absent. It was listed here originally, but nothing
# ever imported it: MDTraj covers every metric FlexAppeal computes and owns the
# trajectory formats. Carrying it meant a dependency in the droplet's install
# and in every generated bundle's environment solve, for nothing.
mdtraj>=1.10
# Pose clustering for the binding panels: average-linkage over a pairwise ligand
# RMSD matrix. Without it those panels are simply absent, which the Analysis tab
# handles, but the convergence sub-score inputs are worth having on the server.
scipy>=1.11

# The chemistry the binding panels need: MMFF94 ligand strain, the rotatable-bond
# and torsion-flip counts, and the 2D depiction shaded by atom mobility. Bond
# orders are inferred from the trajectory's own coordinates, so no chemical
# definition travels in the .fxa and none is needed here.
#
# This was left out originally, on the reasoning that a chemistry toolkit was too
# much to carry for two charts on a small box. Both halves of that were wrong: it
# is three panels and the depiction, which is most of what a reader comes to a
# ligand run for, and the box has 89 GB free against a wheel of about 35 MB. The
# import is still guarded in measure.py, because a bundle's own environment is
# solved separately and may not have it.
rdkit>=2024.3

# Needed by the web app despite being a terminal library, because the /reanalyse
# route spawns FlexAppeal.py as a detached subprocess (webapp.py) and the CLI
# imports flexappeal/console.py at module scope. Its output goes to DEVNULL, so
# nothing here is ever seen -- but the import still has to succeed, and without
# this line re-analysis fails on the droplet with an ImportError that the
# browser only ever sees as a job that never finishes.
#
# psutil is deliberately NOT here: only the generated run/analyse scripts use it,
# and those run in the bundle's own environment on the user's machine.
rich>=13.0
